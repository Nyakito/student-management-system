# Student Management System

## Project Overview

The Student Management System is a web-based application designed to organize and manage student academic records.

The goal is to provide a centralized interface for accessing student information, monitoring academic performance, tracking fee payments and generating useful student statistics.

The application aims to make student record management more organized, accessible and efficient.

## Core Features

### Student Records
- Maintain student information, including names, identification numbers, ages and enrolled courses.
- Retrieve individual student records using their identification numbers.
- Display relevant student information in an organized format.

### Academic Performance
- Calculate student grades based on their marks.
- Determine whether students have passed or failed.
- Generate individual student reports.
- Calculate total marks and class averages.
- Identify high-performing students and students requiring academic attention.

### Student Statistics
- Calculate the total number of students.
- Calculate aggregate and average marks.
- Track the number of students who have passed or failed.
- Monitor fee payment statistics.

### Fee Management
- Identify students with outstanding fee payments.
- Generate lists of students with pending fees.
- Monitor payment status across student records.

### Course Management
- Track the courses students are enrolled in.
- Support updating student course information.

## Running the Project Locally

### Requirements
- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate into the project directory:

```bash
cd student-management
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## Project Objective

The long-term objective is to develop a practical student management application that brings student records, academic reporting, course information and fee monitoring into one organized system.
